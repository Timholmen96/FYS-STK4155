\subsection{NeuralNetwork}
The Neural network creates the architecture, predicts by feed forward, 
and calculates the cost function based on the input values and the target values.  
It is a class which is initiated with input size, output sizes,
activation functions and its derivatives, the cost function and
its derivative, and the seed which ensures consistency when
creating the random initial values (rng) of the weights. The chosen
seed is 2026 for the regression problem.  
The architecture of the layers is created inside the class and saved as an attribute, 
by iterating over the output sizes and creating the initial weights and biases.

    $$b = zeros(output size)$$

\subsubsection{Feed-forward pass}
This first part of the network is the feed forward,
it sends he input values through the layers, each layers 
activation function is applied and the output layer is
calculated by the chosen activaiton function, which is the
identity for the regression problem. 
% LLM Declaration: Edit skeleton
The feed-forward procedure is as follows:
\begin{align}
    \mathbf{a}^{(0)} &= \mathbf{x}, \\
    \mathbf{z}^{(l)} &= \mathbf{a}^{(l-1)} W^{(l)} + \mathbf{b}^{(l)}, \\
    \mathbf{a}^{(l)} &= \phi^{(l)}\!\left(\mathbf{z}^{(l)}\right),
    \qquad l = 1, \ldots, L, \\
    \hat{\mathbf{y}} &= \mathbf{a}^{(L)}.
\end{align}
For backpropagation, it is important to save the input values,
the z values and the output values a during the feed forward.
\subsubsection{Backpropagation}
The backpropagation is the most important part of the neural network,
as it is this process that creates the gradients of each layer, which are used
to update the weights and biases. This process is different depending
on the cost function, since the derivative of the cost function 
is the value we want to minimize. Thus it is different for the
regression problem, which uses mean squared error, and the classification
which uses cross entropy. 
The input layers, the z values and the output values a is generated
by the feed forward pass saver, the backpropagation iterates backwards,
from the last layer to the first.

Regressor, mean squared error
\begin{align}
\text{Output layer:}\quad
    \frac{\partial C}{\partial a^{(L)}}
    &= \text{costfunction derivative}, \\[4pt]
\text{Hidden layer:}\quad
    \frac{\partial C}{\partial a^{(l)}}
    &= \delta^{(l+1)} \left(W^{(l+1)}\right)^\top, \\[4pt]
\delta^{(l)}
    = \frac{\partial C}{\partial z^{(l)}}
    &= \frac{\partial C}{\partial a^{(l)}} \odot
       \sigma'\!\left(z^{(l)}\right), \\[4pt]
\frac{\partial C}{\partial W^{(l)}}
    &= \left(a^{(l-1)}\right)^\top \delta^{(l)}, \\[4pt]
\frac{\partial C}{\partial b^{(l)}}
    &= \sum_{i=1}^{N} \delta_i^{(l)}, \\[4pt]
\nabla^{(l)}
    &= \left(
       \frac{\partial C}{\partial W^{(l)}},
       \frac{\partial C}{\partial b^{(l)}}
       \right).
\end{align}
