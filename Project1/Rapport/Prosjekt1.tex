\begin{abstract}
This project explores the data analysis methods that have contributed
to the development of modern machine learning. The main objective is
to study regression methods in detail, including ordinary least squares,
Ridge regression and Lasso regression. Resampling techniques, such as
bootstrap and cross-validation, allow us to evaluate and select the
most suitable method for the problem.
To optimise the model parameters, we use gradient descent and investigate
different methods for performing derivative-based optimisation.
Cross-validation helps select hyperparameters, such as polynomial degree
and regularisation strength. We have studied Newton's method and
automatic differentiation to support the optimisation of model parameters.
The polynomial models are fitted to a specific one-dimensional function,
known as the Runge function, with added noise, providing a known analytical
function against which the predictions can be compared.
\end{abstract}

\section{Introduction}
\subsection{2a The motivation.}

The reason we want to fit a function to data is that we want to
predict the value of the function to new unknown data points. For fitting a function to
data points, we use polynomials, and we want to find the best polynomial that fits the data.
The best polynomial is the one that minimizes the mean squared error (MSE) between the predicted values and the true values (for the known data).
The MSE can be decomposed into three components: bias, variance and irreducible error.
\[
  \mathrm{MSE} = \mathrm{Bias}^2 + \operatorname{Var}[\tilde{y}]
  + \text{irreducible noise}
\]
The bias measures how far the average prediction is from the truth.
The variance measures how much the prediction moves when the training
set is redrawn.
The irreducible error is the variance of the noise itself,
which is baked into the data such that the model cannot predict it. \cite[p.~62]{LectureNotes}
The bias-variance tradeoff is the balance between bias and variance, in which we minimize the MSE. We do not want
an overfitted model, which has low bias and high variance, nor do we want an underfitted model, which has high bias and low variance.
Optimally, we want a model that is just right, with low bias and low variance.
When fitting a polynomial to data, we want to find the right degree of the polynomial and
the right parameters for each degree. For example if there is a linear relationship between
the data points, and we can assume this by looking at the data, we use a second order polynomial
to describe the data, and the parameters are the coefficients of the polynomial, which can be
changed in accordance with the relationship between the data points.
The parameters are found by minimizing the MSE between the model prediction and datapoints,
for avoiding overfitting, we can split the data into training and testing sets, to se how well
the model performs on unseen data. We can use regularization methods, such as ridge regression
and lasso regression, to regularize the model and avoid overfitting, and thus lower the variance, while maintaining a good bias.
We can also use resampling methods, such as bootstrap and k-fold cross validation, to estimate the performance of the model on unseen data,
and thus choose the best model for the data.

With lasso regression, we do not have the analytical solution for the gradient, as we do for OLS and Ridge, and we have to use gradient descent to find the optimal parameters.
Gradient descent is an optimization algorithm inspired by newtons method, which is used to find the minimum of a function.
The function we want to minimize is the cost function, which is the MSE between the predicted values and the true values.
The gradient descent algorithm uses the derivative of the cost function to find the direction of steepest descent,
and then take steps in that direction, with a step size determined by the learning rate.
We can use different optimization algorithms, such as momentum, adagrad, rmsprop and adam,
where the learning rate of the descent is dependent on the iteration number to improve the convergence of gradient descent.
After exploring the different methods, we can compare them with cross validation, and choose the best model for the data.

\subsection{2b What has been done and what i do.}
The linear models with OLS nad Ridge have been implemented, and both have close form solutions, thus they can be solved without gradient descent.
Lasso regression has been implemented, but it does not have a close form solution, thus we have to use gradient descent to find the optimal parameters.
The project starts with the implementation of OLS and Ridge regression, OLS uses the least square distance between model and data to find the optimal parameters, this is the cost function, and the optimal parameters are found by minimizing the cost function.
Ridge regression does the same, but adds a regularizatin term to the cost function, which penalizes large parameters, and thus avoids overfitting.
What ridge removes in variance, it adds in increased bias, which will be discussed as the bias-variance tradeoff. For exploring this theme we have

\subsection{The data}
In this project, the input data is normally distributed, and the output data is generated by Runge's function, with added noise,
Runge Function which is a one-dimensional function of second order.
\[
  f(x) = \frac{1}{1 + 25x^2}
\]
From the beginning, we have created a relation between the input and output data. This is helpful since the project is research in machine learning methods, it is usefull to know the exact solution.
The noise is normally distributed, with a mean of 0 and a variable standard deviation.
From the form of the runge function, we can see that the function has a maximum at x=0, and the function is symmetric around this point,
for values larger than [-1,1], the function approahes zero.
Thus we will focus on data which is normally distributed between -1 and 1.
The output is generated by adding noise $\sigma$ to the runge fucnction defined above, and the noise is normally distributed with a mean of 0 and a standard deviation of $\sigma$.

The input value x is transformed into a design matrix $X$,
where the columns describe a polynomial of variable degree $d$,
in such a way that the first column is $x^0$, the intrcept, the second column is $x^1$, and so on, up to $x^{d}$.
The rows of the matrix are the data points, and are thus copied and multiplied according to the polynomial degree, or the column of the matrice.
\begin{equation}
\mathbf{X} =
\begin{pmatrix}
1 & x_1 & x_1^2 & \cdots & x_1^d \\
1 & x_2 & x_2^2 & \cdots & x_2^d \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & x_n & x_n^2 & \cdots & x_n^d
\end{pmatrix}
\in \mathbb{R}^{n \times (d+1)}.
\label{eq:design_matrix}
\end{equation}

\subsection{Linear Regression}
The basic idea of linear regression is, by using a polynomial $f(x)$
of fixed degree to describe the data points given the input
data x, to adjust the coefficients in such a way that the difference
between the predicted values of the model $f(x)$ and the true output value
$y(x)$. The coefficients are adjusted so that mean of the sum of the difference squared
is minimised, which is the basis for the name least squares regression.
\subsubsection{Ordinary Least Sqaures}
Thus the cost function, for least squared, is written mathematically:
\begin{equation}
  C(\theta) = \frac{1}{n}\lVert y - X\theta\rVert_2^2
\end{equation}
\cite[p.~81]{LectureNotes}
This is the optimization problem, to adjust the parameter $\theta$ such that the cost function is minimized.
The cost function is convex, and the minima is in the extremum point the $\nabla_{theta}C(\theta)=0$. 
The gradient is
\begin{equation}
  \nabla_{\theta} C_{\mathrm{OLS}}(\theta)
  = \frac{2}{n}X^T(X\theta-y).
\end{equation}
Setting this gradient to zero gives the normal equations:
\begin{equation}
  \hat{\theta} = (X^{T}X)^{-1}X^{T}y
\end{equation}
\cite[p.~81]{LectureNotes}
Through singular value decomposition~\cite[p.~42]{LectureNotes}, it can be shown that the best estimate for this theta, which
minimizez the cost function, is the pseudioinverse of X multiplied by the output data y,
\begin{equation}
  \hat{\theta} = X^{+}y
\end{equation} \cite[p.~82]{LectureNotes}
The pseudoinverse is solved by the numpy package \texttt{np.linalg.pinv(X)}, on the assumption that
the columns of $X$ are linearly independent, such that $X^{T}X = I$ and $X^{+}=(X^{T}X)^{-1}X^{T}=I^{-1}X^{T}=X^{T}$.

It is safe to assume that the columns are linearly independent, since the number of columns (degrees d) is much smaller than the number of rows (data points n),
the possibility of one column being a linear combination of the other colmuns is close to zero.

The data is split into training and test data as described above, and the training data is normalised
as explained above. This ensures that the model can predict on the test data of X, and the predictions
can be used against the test data of y to calculate the mean squared error MSE and coefficient of determination $R^2$, how these values are calculated will be explained in \hyperref[sec:PF]{measures of quality}
This procedure is done for different degrees of the polynomial design matrice. The parameters are plotted against degree, and the predicted
models for different degrees are plotted against the runge function, for different values of the noise $\sigma$.

Here we go

\subsection{Ridge Regression}
Ridge regression adds a penalty on the squard length of the parameter vector,
and the cost function is;
\begin{equation}
C_{\mathrm{Ridge}}(\bm{\theta})
= \frac{1}{n}
  \left\|\bm{y}-\bm{X}\bm{\theta}\right\|_2^2
  + \lambda\left\|\bm{\theta}\right\|_2^2,
\qquad \lambda \geq 0.
\label{eq:ridge_cost}
\end{equation}
with $\lVert\theta\rVert_2^2 = \sum_{j}\theta_j^2$ \newline 
The gradient for this cost function is given by
\begin{equation}
  \nabla_{\theta} C_{\mathrm{Ridge}}(\theta)
  = \frac{2}{n}X^T(X\theta-y)
    + 2\lambda \theta.
\end{equation}
Setting this to zero and solving for theta, ignoring the factor 1/n, 
gives the closed form solution to this problem
\begin{equation}
  \hat{\theta}_{\mathrm{Ridge}} =
  (X^{T}X + \lambda I)^{-1}X^{T}y
\label{eq:ridge_sol}
\end{equation}
$I$ is the $p\times p$ identity matrix. The penalty adds $\lambda$ to the eigenvalues
of $\bm{X}^{T}\bm{X}$. \cite[p.~87]{LectureNotes}
Supposing the design matrice is orthonormal, $X^{T}X=I$: then $\hat{\theta}_{\mathrm{OLS}}=X^{T}y$ and
\begin{equation}
  \hat{\theta}_{\mathrm{Ridge}}=
  (I + \lambda I)^{-1}X^{T}y =
  \frac{1}{1+\lambda}\hat{\theta}_{\mathrm{OLS}}
\label{eq:ROLS_Relation}
\end{equation}
So every coefficient is scaled by the same factor, and the estimator
tends to zero as $\lambda \to \infty$. Ridge shrinks all coefficients proportionally;
it never sets any of the exactly to zero.

\subsubsection{Pseudocode Ridge}
Here we go:
\begin{lstlisting}[
    basicstyle=\ttfamily\footnotesize,
    breaklines=true,
    frame=single,
    caption={Ridge regression without penalizing the intercept.},
    label={lst:ridge}
]
lambdas <- logspace(-3, 2, 5)

FOR degree = 0, ..., 15:
    X_train, X_test, y_train, y_test
        <- PrepareData(x, y, degree)

    P <- IdentityMatrix(degree + 1)
    P[0, 0] <- 0

    FOR lambda in lambdas:
        A <- transpose(X_train) * X_train
             + lambda * P

        b <- transpose(X_train) * y_train

        theta <- pseudoinverse(A) * b

        prediction <- X_test * theta

        mse <- MSE(y_test, prediction)
        r2  <- R2(y_test, prediction)

        Store degree, lambda, theta, mse and r2
\end{lstlisting}

\subsection{Lasso Regression}
Replacing the 2-norm penalty of Ridge by a 1-norm gives the cost function
\begin{equation}
  \begin{aligned}
  C_{\mathrm{Lasso}}(\theta)
  &= \frac{1}{n}\lVert y - X\theta\rVert_2^2 + \lambda\lVert\theta\rVert_1, \\
  \lVert\theta\rVert_1 &= \sum_{j=0}^{p-1}|\theta_j|
  \end{aligned}
\label{eq:Lasso_cost}
\end{equation}
Which is the Lasso - least absolute shrinkage and selection operator. The Lasso
sets coefficients exactly t ozero, and thereby perfoms variable selection as part of the fitting. \cite[p.~90]{LectureNotes}
The lasso has no closed form solution, since differentiating the \hyperref[eq:Lasso_cost]{cost function},
requires the derivative of the absolute value of $\theta$:
 \begin{equation}
\frac{d|\theta|}{d\theta}
= \operatorname{sgn}(\theta)
= \begin{cases}
+1, & \theta > 0, \\
-1, & \theta < 0.
\end{cases}
\label{eq:abs_derivative}
\end{equation}
This equation is undefined at th origin, theta = 0, thus the close form solution is lost,
but a solution can still be found through the soft thresholding operator and gradient descent methods,
which will be explained in \hyperref[sec:GD]{section gradient descent}.
here is the soft thresholding operator for $X=I$
\begin{equation}
  \begin{aligned}
  \hat{\theta}_i^{\mathrm{Lasso}} &= S_{\lambda/2}(y) \\
  &= \operatorname{sgn}(y)\max(|y| - \lambda/2, 0)
  \end{aligned}
\end{equation}
\cite[p.~91]{LectureNotes}
The selection property makes the lasso the natural first tool when the
number of parameters is large and most fatures are believed irrelevant.
Solving the lasso regession problem requires a gradient descent method, 
which will be explained in \hyperref[sec:GD]{Gradient descent} and 
\hyperref[subsec:Lasso_GD]{Lasso}

\subsubsection{Measures of quality}
\label{sec:PF}
\paragraph{Coefficient of determination}
This
\begin{equation}
\begin{aligned}
R^2 &= 1-\frac{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
          {\sum_{i=1}^{n}(y_i-\bar{y})^2},
\\
\bar{y} &= \frac{1}{n}\sum_{i=1}^{n}y_i.
\end{aligned}
\label{eq:r2}
\end{equation}

\paragraph{Mean squared error}
\begin{equation}
\mathrm{MSE}
= \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2.
\label{eq:mse}
\end{equation}

\paragraph{Bias}
For this project we will look at bias squared, the reason for this
is that the squared values are positive, such that the terms will not
cancel when we take the mean. the equation is.
\begin{equation}
  \begin{aligned}
  \mathrm{Bias}^2 &= \frac{1}{n}\sum_{i}(f_i - \mathbb{E}[\hat{\boldsymbol{y}}])^2, \\
  \mathbb{E}[\hat{\boldsymbol{y}}] &= \frac{1}{n}\sum_{i} \hat{y}_i
  \end{aligned}
  \label{eq:Bias}
\end{equation}
The bias measurs how far the average prediction $\mathbb{E}[\hat{\boldsymbol{y}}]$
is from the fruth $f(x)$. \cite[p.~61-62]{LectureNotes}

In the case of this project, the function $f(x)$ is the runge function.
The details on this will be discussed in the \hyperref[sec:BV]{bias variance tradeoff},
since the data $y = f(x) + \epsilon$ includes noise.

\paragraph{Variance}
The variance is closely related to the standard deviation, which is
the square root of the variance, and tells how much the data varies
within the sample.
\begin{equation}
  \operatorname{Var}[\hat{\boldsymbol{y}}]
  = \frac{1}{n}\sum_{i}(\hat{y}_i - \mathbb{E}[\hat{\boldsymbol{y}}])^2
\end{equation} \cite[p.~62]{LectureNotes}
The variance measures how much the prediction moves when the training set is
redrawn. (Feil?)

\subsubsection{Bias-Variance tradeoff}
\label{sec:BV}
Before we perform an analysis of the bias variance tradeoff on the test data,
we mak a figure similar to Fig. 2.11 of Hastie, Tibshirani and Friedman. \cite[p.~38]{StatisticalLearning}
This figure displays only the test and training MSE. The test MSE
can be used to indicate possible regions of low/ high bias and variance.
To solve this, different values of noise, datapoints and polynomial degree is explored.

The bias variance tradeoff equation:
\begin{equation}
  \begin{aligned}
  &\mathbb{E}[
    (\boldsymbol{y}-\hat{\boldsymbol{y}})^2] \\
    &\quad = \frac{1}{n}\sum_{i=1}^{n}
    \left(f_i-\mathbb{E}_{\mathcal{D}}[\hat{y}_i]\right)^2
    \\
    &\qquad + \frac{1}{n}\sum_{i=1}^{n}
    \left(
        \hat{y}_i-\mathbb{E}[\hat{y}_i]
    \right)^2 + \sigma^2
  \end{aligned}
  \label{eq:bias_variance}
\end{equation}

\begin{equation}
  \mathrm{MSE} = \mathrm{Bias}^2 + \operatorname{Var}[\hat{y}]
  + \text{irreducible noise}
\end{equation}
Our empirical bias-related term compares the mean
prediction with the noisy test targets,
rather than with the noise-free function.
Consequently, it also contains a contribution from
the test noise and should not be interpreted as
the squared bias alone.

\subsubsection{Bootstrap}
We study the bias variance tradeoff by implementing the bootstrap resampling technique.
For studying this tradeoff we will only use ordinary least square for simplicity.
The bootstrap approximates the sampling distribution of an estimator by repeatedly sampling
from the observed data.
\begin{enumerate}
    \item Draw with replacement n values from the observations
    $\boldsymbol{x} = (x_0,\ldots,x_{n-1})$, forming a resample $\boldsymbol{x^*}$
    \item Evaluate the estimator on the resample to obtain $\hat{\theta^*}$
    \item Repeat k times
\end{enumerate}
\cite[p.~65]{LectureNotes}
The gist is that since $\hat{\theta} = \hat{\theta(\boldsymbol{X})}$ is
a function of random variables, theta itself is a random variable with some
probability distribution function $p(t)$. The different bootstrap samples,
pulls different random samples from the training data, with replacement,
and each produce different fitted coefficients and therefore different predictions.
The number of samples is chosen as a variable, in our case 40, 100 and 300 samples,
and all the models are used to calculate the man squard error, bias and variance between
all the fitted models and the test data. This is done for each degree of the polynomial.
To pull the random data from the training data, we use sci-kit function \texttt{resample}
for pulling the random bootstrap data.

\paragraph{Bootstrap Pseudocode}
LLM Declaration:
This pseudocode is a copy of the reference project code c: Bootstrap \cite{Timholmen96FYSSTK4155Prosjektarbeid}
created with help of OpenAI codex \cite{Codex}
\begin{lstlisting}[
    basicstyle=\ttfamily\footnotesize,
    breaklines=true,
    frame=single,
    caption={Bootstrap estimation of prediction error,
             a bias-related term, and variance for OLS.},
    label={lst:bootstrap}
]
FUNCTION BootstrapBiasVariance(n_bs, maxdeg, seed):
    Initialize random generator using seed
    Generate n_bs bootstrap seeds

    error    <- zeros(maxdeg + 1)
    bias     <- zeros(maxdeg + 1)
    variance <- zeros(maxdeg + 1)

    FOR degree = 0, ..., maxdeg:
        X <- DesignMatrix(x, degree)

        Split X and y into:
            70% training data
            30% test data
        Use random seed 2026

        n_test <- number of test observations
        predictions <- zeros(n_test, n_bs)

        FOR b = 0, ..., n_bs - 1:
            Draw paired rows from X_train and y_train
                with replacement
                using bootstrap seed b
                and preserving the training set size

            X_bs, y_bs <- bootstrap sample

            theta <- pseudoinverse(X_bs) * y_bs

            predictions[:, b] <- X_test * theta

        mean_prediction <- row means of predictions
        point_variance  <- row population variances
                           of predictions

        targets <- repeat y_test in n_bs columns

        error[degree] <- mean(
            (targets - predictions)^2
        )

        bias[degree] <- mean(
            (y_test - mean_prediction)^2
        )

        variance[degree] <- mean(point_variance)

    RETURN error, bias, variance
\end{lstlisting}

\subsubsection{Kfold Cross Validation}
The data are divided into k roughly equal, mutually exclusive and
exhaustive subsets, the folds. Each in turn plays the role of the
test set while the union of the k-1 folds serve as the training set.
Each observation is therefore used for testing exactly once and for
training exactly k-1 times. The procedure is:
\begin{enumerate}
  \item Shuffle the data set at random
  \item Split into k folds.
  \item For each fold: hold it out, fit the model on the remaining folds,
  evaluate on the held out folds and discard the model.
  \item Summarize the model by the mean, the spread, of the k scores.
\end{enumerate}
\cite[p.~66]{LectureNotes}
The k fold cross validation is solved with closed form solutions
for ridge and OLS, and with ski-kit functions Linearregression and Ridge.
The mean value of the mean squared error of all folds is calculated analytically
and with sci-kit function cross-val-score, and the difference between analytical and
sci-kit solutions are calculated. 5 fold and 10 fold cross validation is used,
and the ridge regression is calculated for different values of lambda, the penalty.
The sci-kit method is used to ensure that the results agree with the results obtained
numerically.

The cross validation is used to find the best degree, the best lambda value for ridge,
and the best overall model, also the difference between the 5 fold and the 10 fold
cross validation result is shown.

\subsubsection{Plain gradient descent}
The gradient descent methods introduced is a method for finding
the optimal parameter $\theta$, and is thus a replacement for
the closed form solutions of OLS and Ridge, and gives a solution
for the lasso regression problem, which had no analytical CF solution.
In this regard the previous solutions for OLS and ridge can be used
to verify that the gradient descent methods converge to the analytical solutions.

In its simplest form, the gradient descent method can be written
\begin{equation}
  \theta_{k+1} = \theta_k - \eta\nabla_{\theta}C(\theta_k)
\end{equation}
\cite{Project1}
The gradients of the cost function, will be solved both analytically
and with automatic differentation (JAX), and the results will be compared
to prove that they agree to numerical precision.

Initially the learning rate $\eta$ is guessd and adjusted for convergence
over the number of iterations. But the learning rate has some limits,
as long as the Hessian is known, as it is for Ridge and OLS, we can 
calculate this limit, the limit of convergence:
For all directions of the cost function to converge we need
$0 < \eta < \frac{2}{\lambda_{max}}$, where $\lambda_{max}$ is 
the largest eigen value of the Hessian. Since the Hessian is the 
second derivative of the cost function, the largest eigenvalue
is the steepest direction, and the smallest eigenvalue is the 
slowest direction, thus we can define the condition number, $\kappa = \frac{\lambda_{max}}{\lambda_{min}}$
, which is proportional to the number of iterations needed to reduce
the error by a fixed factor. The bound is set by the steepest direction,
and a flat direction (0). Presumably the number of iterations reaches 
its minimum at $\eta = \frac{2}{\lambda_{min}+\lambda_{max}}$, and diverges
exactly at $\frac{2}{\lambda_{max}}$. \newline 
Momentum, Adagrad, RMSprop and Adam are advanced gradient descent methods
where the learning rate $\eta(n)$ is updated during the iteration.
Opposed to plain gradient descent where the learning rate is constant.
The more advanced methods are more suitable for cases where we cannot
analytically calculate the Hessian of the cost function. 

\subsubsection{Pseudocode GD}
LLM Declaration. This pseudocode is a pseudo copy of the reference project code \textit{f: Momentum, Adagrad, RMSprop and Adam}

The following two pseudocodes show simplified interfaces for the optimisation

\begin{lstlisting}[

$\theta \gets \theta_0$

Set learning rate to $\gamma$

    grad <- gradient($\theta$)

    Append a copy of $\theta$ to history
    Advance iteration count

\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}[
    basicstyle=\ttfamily\footnotesize,
    breaklines=true,
    frame=single,
    mathescape=true,
    caption={Momentum.},
    label={lst:momentum}
]
INPUT $C$, $\theta_0$, $T$, $\gamma>0$, $0\leq\beta<1$

$v_0 \gets \mathbf{0}$

FOR $t=1,\ldots,T$:
    $g_t \gets \nabla C(\theta_{t-1})$

% Adagrad
\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}[
    basicstyle=\ttfamily\footnotesize,
    breaklines=true,
    frame=single,
    mathescape=true,
    caption={AdaGrad.},
    label={lst:adagrad}
]
INPUT $C$, $\theta_0$, $T$, $\gamma>0$, $\varepsilon>0$

$r_0 \gets \mathbf{0}$

FOR $t=1,\ldots,T$:
    $g_t \gets \nabla C(\theta_{t-1})$
    $r_t \gets r_{t-1}+g_t^2$
    $\theta_t \gets \theta_{t-1}-\frac{\gamma}{\sqrt{\varepsilon+r_t}}g_t$

RETURN $\theta_T$
\end{lstlisting}
\end{minipage}

\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}[
    basicstyle=\ttfamily\footnotesize,
    breaklines=true,
    frame=single,
    mathescape=true,
    caption={RMSProp.},
    label={lst:rmsprop}
]
INPUT $C$, $\theta_0$, $T$, $\gamma>0$, $0\leq\rho<1$, $\varepsilon>0$

$r_0 \gets \mathbf{0}$

FOR $t=1,\ldots,T$:
    $g_t \gets \nabla C(\theta_{t-1})$
    $r_t \gets \rho r_{t-1}+(1-\rho)g_t^2$
    $\theta_t \gets \theta_{t-1}-\frac{\gamma}{\sqrt{\varepsilon+r_t}}g_t$

RETURN $\theta_T$
\end{lstlisting}
\end{minipage}

\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}[
    basicstyle=\ttfamily\footnotesize,
    lineskip=3pt,
    breaklines=true,
    frame=single,
    mathescape=true,
    caption={Adam.},
    label={lst:adam}
]
INPUT $C$, $\theta_0$, $T$, $\gamma>0$,
      $0\leq\beta_1,\beta_2<1$, $\varepsilon>0$

$m_0 \gets \mathbf{0}$
$r_0 \gets \mathbf{0}$

FOR $t=1,\ldots,T$:
    $g_t \gets \nabla C(\theta_{t-1})$
    $m_t \gets \beta_1 m_{t-1}+(1-\beta_1)g_t$
    $r_t \gets \beta_2 r_{t-1}+(1-\beta_2)g_t^2$
    $\hat{m}_t \gets \frac{m_t}{1-\beta_1^t}$
    $\hat{r}_t \gets \frac{r_t}{1-\beta_2^t}$
    $\theta_t \gets \theta_{t-1}-\frac{\gamma}{\sqrt{\hat{r}_t}+\varepsilon}\hat{m}_t$

RETURN $\theta_T$
\end{lstlisting}
\end{minipage}

\subsubsection{Lasso Gradient descent}
\label{subsec:Lasso_GD}
The Lasso cost function is the mean squared error plus an
L1 penalty. The intercept $\theta_0$ is not penalised:
\begin{equation}
  C_{\mathrm{Lasso}}(\theta)
  = \frac{1}{n}\|X\theta-y\|_2^2
    + \lambda\sum_{j=1}^{p-1}|\theta_j|.
\end{equation}
Here, $p$ is the number of coefficients, including the intercept.

Since the L1 penalty is not differentiable at zero,
we use a subgradient:
\begin{equation}
  g_{\mathrm{Lasso}}(\theta)
  = \frac{2}{n}X^T(X\theta-y) + \lambda s(\theta).
\end{equation}
The first term is the MSE gradient. The penalty contribution
is defined by $s_0=0$ and, for $j=1,\ldots,p-1$,
\begin{equation}
  s_j =
  \begin{cases}
    -1, & \theta_j < 0, \\
    0, & \theta_j = 0, \\
    1, & \theta_j > 0.
  \end{cases}
\end{equation}
At zero, we choose $s_j=0$, which is a valid subgradient
of the absolute value from the interval $[-1,1]$.
This will be the input for the optimization pseudocode explained
in gradient descent, and thus the optimal parameters will
be found through gradient descent.

\subsection{Experimental setup}
\noindent\textit{LLM Declaration:} This section was generated with the assistance of OpenAI Codex \cite{Codex}, which analyzed the \texttt{Full\_Project.ipynb}\cite{Timholmen96FYSSTK4155Prosjektarbeid} code structure and helped organize the description of the experimental setup.

We generate 350 observations from the Runge function,

and Gaussian noise with standard deviation $\sigma=0.25$.

Polynomial features are standardised using training-set statistics,
except in the bias--variance and bootstrap experiments.
The intercept is excluded from regularisation.

OLS and Ridge are evaluated for polynomial degrees 0--15,
with Ridge penalties ranging from $10^{-3}$ to $10^2$.
The bias--variance analysis extends to degree 25.
Bootstrap experiments use 40, 100 and 300 resamples.
Shuffled 5-fold and 10-fold cross-validation compare OLS, Ridge
and Lasso for degrees 0--14 and several regularisation strengths.
Performance is measured using MSE and $R^2$, with mean validation
MSE used for model comparison.

The optimisation experiments use degree 5 and a regularisation
strength of $0.01$ for Ridge and Lasso.
Analytical gradients are compared with automatic differentiation
using JAX. Plain gradient descent, Momentum, AdaGrad, RMSProp
and Adam are evaluated at several learning rates.
Lasso uses a subgradient of the $L_1$ penalty.
Convergence is assessed against analytical OLS/Ridge solutions
and a scikit-learn Lasso reference, using parameter error,
iteration count and execution time.

Finally, OLS, Ridge and Lasso are compared using shuffled
5-fold and 10-fold cross-validation for polynomial degrees 0--14.
Several regularisation strengths are tested for Ridge and Lasso.
Features are standardised within each training fold.
The models are compared using mean validation MSE and its
standard deviation across folds, selecting the degree and
regularisation strength with the lowest mean MSE.
