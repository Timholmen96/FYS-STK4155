\section{Introduction} 
\subsection{2a The motivation.}

The reason we want to fit a function to data is that we want to 
predict the value of the function to new unknown data points. For fitting a function to
data points, we use polynomials, and we want to find the best polynomial that fits the data.
The best polynomial is the one that minimizes the mean squared error (MSE) between the predicted values and the true values (for the known data). 
The MSE can be decomposed into three components: bias, variance and irreducible error.
$$ MSE = Bias^2 + Var[\tilde{y}] + irreducible \ noise$$ 
The bias measures how far the average prediction is from the truth.
The variance measures how much the prediction moves when the training
set is redrawn. 
The irreducible error is the variance of the noise itself, 
which is baked into the data and the model cannot predict it. \cite[p.~62]{LectureNotes} 
The bias-variance tradeoff is the balance between bias and variance, in which we minimize the MSE. We do not want 
an overfitted model, which has low bias and high variance, nor do we want an underfitted model, which has high bias and low variance. 
Optimally, we want a model that is just right, with low bias and low variance.
When fitting a polynomial to data, we want to find the right degree of the polynomial and
the right parameters for each degree. For example if there is a linear relationship between
the data points, and we can assume this by looking at the data, we use a second order polynomial
to describe the data, and the parameters are the coefficients of the polynomial, which can be
changed in accordance with the relationship between the data points. 
The parameters are found by minimizing the MSE between the model prediction and datapoints, 
for avoiding overfitting, we can split the data into training and testing sets, to se how well 
the model performs on unseen data. We can use regularization methods, such as ridge regression 
and lasso regression, to regularize the model and avoid overfitting, and thus lower the variance, while maintaining a good bias. 
We can also use resampling methods, such as bootstrap and k-fold cross validation, to estimate the performance of the model on unseen data,
and thus choose the best model for the data. \newline
With lasso regression, we do not have the analytical solution for the gradient, as we do for OLS and Ridge, and we have to use gradient descent to find the optimal parameters.
"Gradient descent is an optimization algorithm inspired by newtons method, which is used to find the minimum of a function. 
The function we want to minimize is the cost function, which is the MSE between the predicted values and the true values. 
The gradient descent algorithm uses the derivative of the cost function to find the direction of steepest descent,
 and then takes a step in that direction, with a step size determined by the learning rate. 
 We can use different optimization algorithms, such as momentum, adagrad, rmsprop and adam,
where the learning rate is dependent on the iteration number to improve the convergence of gradient descent." - AI
After exploring the different methods, we can compare them with cross validation, and choose the best model for the data.
